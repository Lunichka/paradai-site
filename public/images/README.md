# Картинки сайта

Пути к файлам задаются в `src/data/content.ts`. Чтобы заменить картинку, положите файл с тем же именем
или поправьте путь в `content.ts`. Формат везде WebP: он вдвое-втрое легче JPG/PNG и поддерживает прозрачность.

## hero/ — вырезки с прозрачным фоном (элементы параллакса)
- `chocolate.webp` — открытая плитка. Холст не обрезан: размер плитки на экране зависит от пропорций холста
- `pod.webp` — раскрытый стручок какао
- `leaf.webp` — лист какао
- `bean-1.webp`, `bean-2.webp`, `bean-3.webp` — бобы (повторяются по кругу, всего на экране шесть)
- `triangle.webp` — золотой треугольник, буква «A» в PAR▲DAI. Высота = высоте заглавных букв, поэтому
  в слоте он стоит на базовой линии вместе с PAR и DAI

Как готовить новые вырезки: PNG/WebP с альфа-каналом, длинная сторона 600–1100 px, вокруг объекта немного
прозрачного поля. Без одиночных «пылинок» по краям: из-за них холст растёт, а объект на экране уменьшается.

## gallery/ — фото мастерской (9 шт.)
`01-roasting` … `09-shop`, WebP. Вертикальные — ширина 900 px, горизонтальные — ширина 1200 px.
Вертикальные кадры обрезаются до 4:5, горизонтальные до 4:3. Что остаётся в кадре, задаёт `focus` в `content.ts`.

## products/ — фото плиток и портрет основателя
`phuket-milk-60`, `belize-63`, `sugar-free-77`, `nakhon-58` — фото на ткани; `nakhon-75`, `chanthaburi-70` — вырезки с тенью (прозрачный фон);
`coconut-sugar-70` — маленький исходник (300 px), лучше заменить файлом побольше; `*-lifestyle` — дополнительные кадры для галереи на странице товара;
`founder.webp` — портрет на странице «О нас». Остальные товары пока ссылаются на внешние сайты (см. README в корне).
